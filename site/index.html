논문 요약

사전학습된 이미지 Transformer(인코더)와 텍스트 Transformer(디코더)를 연결해, 잘라 낸 한 줄 글자 이미지를 텍스트로 바꾸는 OCR 모델을 만들고, 대규모 합성 데이터로 사전학습한 뒤 인쇄체·손글씨·장면 글자 벤치마크에서 평가한 연구

문제 정의

CNN·RNN 없이 사전학습 Transformer만으로 글자 인식이 가능한가

모델

이미지 Transformer 인코더 + 텍스트 Transformer 디코더 (62M~558M)

학습

2단계 사전학습 + Fine-tuning, 교차 엔트로피 손실, 데이터 증강

평가

SROIE (F1), IAM (CER), 장면 글자 (단어 정확도)

핵심 개념 (발표 순서)
  1. 전이학습
  2. 인코더-디코더
  3. Self-Attention
  4. 자기회귀 생성
  5. 데이터 증강

논문을 고른 이유

  1. 시험지를 찍으면 풀이를 보여 주는 AI 앱(AI 치팅)이 화제가 된 것을 봄
  2. 이런 앱의 첫 단계인 사진 속 글자를 텍스트로 바꾸는 과정(OCR)이 궁금해짐
  3. 관련 논문을 찾다가 사전학습 Transformer로 OCR을 만든 TrOCR(AAAI 2023)를 알게 됨
  4. 머신러닝 수업 내용과 연결되는 부분이 많아 선택

이 모델을 사용한 이유

전이학습

이미지·텍스트 각각 대규모 데이터로 학습된 가중치 재사용. 글자 데이터만으로 처음부터 학습할 때보다 높은 성능 (SROIE F1: 처음부터 38.24 → 사전학습 모델 초기화 72.75)

Self-Attention

모든 패치가 한 번에 서로를 참고해 줄 전체의 정보 반영. CNN은 층을 쌓아야 넓은 영역을 봄

자기회귀 디코더

앞에서 생성한 토큰을 조건으로 다음 토큰 예측. 언어 지식이 예측에 포함되어 외부 언어모델 불필요

wordpiece 출력

단어 조각 단위 생성으로 문자 단위보다 짧은 출력, 어휘에 없는 단어도 조각으로 표현

TrOCR 미측정

정리

  1. 문제

    기존 OCR은 CNN·RNN·외부 언어모델을 따로 설계하고, 대규모 사전학습 모델을 거의 쓰지 않음

  2. 방법

    사전학습 이미지 Transformer + 텍스트 Transformer 인코더-디코더. 2단계 합성 데이터 사전학습 후 Fine-tuning, 교차 엔트로피 학습

  3. 결과

    SROIE F1 96.58, IAM CER 2.89 (Large). 사전학습·증강 누적 시 SROIE F1 38.24 → 95.84

  4. 의의

    구조 변경 없이 전이학습만으로 인쇄체·손글씨·장면 글자 인식. 검출과 문제 풀이는 별도 모델의 역할
