============================================================
용어 정리
============================================================

발표에 나오는 용어를 분야별로 정리. 각 용어마다 뜻과 개념 설명, 이 논문(또는 자체 실험)에서 어떻게 쓰이는지 순서로 적음.

목차
1. 문제와 데이터
2. 기존 OCR 방법
3. Transformer 기초
4. TrOCR의 부품
5. 학습 방법
6. 평가 지표

============================================================
1. 문제와 데이터
============================================================

[OCR (Optical Character Recognition, 광학 문자 인식)]
----------------------------------------
이미지 속 글자를 읽어 컴퓨터가 다룰 수 있는 텍스트로 바꾸는 기술. 보통 글자 위치를 찾는 검출과 찾은 영역을 읽는 인식 두 단계로 나뉨.
- TrOCR는 이 중 인식 단계만 다룸.

[텍스트 검출 (text detection)]
----------------------------------------
사진 전체에서 글자가 있는 영역(상자)을 찾는 일. 결과는 글자가 아니라 위치.
- TrOCR 논문은 검출을 연구 범위 밖으로 두고, 이미 잘라 낸 한 줄 이미지를 입력으로 씀.

[텍스트 인식 (text recognition)]
----------------------------------------
잘라 낸 글자 영역 이미지를 보고 실제 글자열을 출력하는 일.
- TrOCR가 하는 일. 입력은 한 줄 이미지, 출력은 그 줄의 텍스트.

[SROIE]
----------------------------------------
ICDAR 2019 영수증 OCR 대회 데이터(Scanned Receipts OCR and Information Extraction). 스캔한 영수증에서 잘라 낸 글자 줄.
- 논문의 인쇄체 벤치마크. 단어 단위 F1로 평가. 사전학습·증강 효과를 보는 실험(Table 1·2)도 이 데이터로 함.

[IAM]
----------------------------------------
영어 손글씨 문장 데이터베이스. 여러 사람이 손으로 쓴 문장을 줄 단위로 자른 이미지와 정답 텍스트.
- 논문의 손글씨 벤치마크. 대소문자를 구분한 CER로 평가.

[장면 글자 (scene text)]
----------------------------------------
간판, 표지판, 상품처럼 일상 사진 속에 찍힌 글자. 배경이 복잡하고 글꼴·각도·조명이 제각각이라 문서보다 어려움.
- 논문은 IIIT5K, SVT, IC13, IC15 등 단어 이미지 벤치마크로 평가.

[합성 데이터 (synthetic data)]
----------------------------------------
실제로 모은 데이터가 아니라 프로그램으로 만든 학습 데이터. 글꼴, 배경, 변형을 바꿔 가며 정답과 함께 대량으로 만들 수 있음.
- 2단계 사전학습에 TRDG로 만든 손글씨·인쇄체 줄, 장면 글자용 MJSynth·SynthText를 씀.

============================================================
2. 기존 OCR 방법
============================================================

[CNN (Convolutional Neural Network, 합성곱 신경망)]
----------------------------------------
작은 필터를 이미지 전체에 밀면서 같은 가중치로 특징을 뽑는 신경망. 가까운 픽셀끼리의 패턴(선, 모서리)을 잘 잡음.
- 기존 OCR에서 이미지 특징을 뽑는 부분. TrOCR는 이것을 이미지 Transformer로 바꿈. Table 1의 ResNet50이 CNN.

[RNN (Recurrent Neural Network, 순환 신경망)]
----------------------------------------
이전 시점의 상태를 다음 시점 입력과 함께 쓰는 신경망. 순서가 있는 데이터를 앞에서부터 차례로 처리함.
- 기존 OCR에서 CNN 특징을 왼쪽에서 오른쪽으로 읽으며 문맥을 붙이는 부분. 주로 양방향 LSTM을 씀.

[LSTM (Long Short-Term Memory)]
----------------------------------------
RNN의 한 종류. 게이트로 무엇을 기억하고 잊을지 조절해 긴 순서도 학습할 수 있음. 양방향(BiLSTM)은 앞에서와 뒤에서 모두 읽음.
- 기존 CRNN 계열 OCR의 중간 부품.

[CTC (Connectionist Temporal Classification)]
----------------------------------------
입력 열과 출력 글자 수가 다를 때 쓰는 손실·디코딩 방법. 열마다 글자 또는 빈칸을 예측한 뒤, 연속 중복과 빈칸을 지워 글자열을 만듦.
- 기존 OCR의 출력 방식. 열마다 독립적으로 예측해서 앞 글자를 조건으로 쓰지 않음.

[언어모델 (language model)]
----------------------------------------
문장에서 다음 단어나 글자가 나올 확률을 계산하는 모델. 철자가 그럴듯한지 판단하는 데 쓸 수 있음.
- 기존 OCR은 인식 결과를 따로 학습한 언어모델로 고침. TrOCR는 디코더가 텍스트로 사전학습돼 있어 외부 언어모델을 붙이지 않음.

[대규모 언어모델 (LLM, Large Language Model)]
----------------------------------------
대량의 텍스트로 학습한 매우 큰 언어모델. 질문에 답하고 문제를 풀이하는 텍스트를 생성함.
- 발표에서 AI 치팅 앱의 "문제 풀이" 단계. TrOCR와는 다른 모델이고, TrOCR는 그 앞의 글자 읽기만 맡음.

[Tesseract]
----------------------------------------
Google이 관리해 온 오픈소스 OCR 엔진. 버전 4부터 LSTM 기반 인식기를 씀.
- 논문 SROIE 표의 비교 대상(F1 54.57)이자 자체 실험의 비교 대상.

============================================================
3. Transformer 기초
============================================================

[Transformer]
----------------------------------------
순환 없이 Attention만으로 순서 데이터를 처리하는 신경망 구조. 모든 위치를 한 번에 보고 서로 얼마나 참고할지를 계산함. 2017년 번역 모델로 처음 나옴.
- TrOCR는 이미지 쪽과 텍스트 쪽 모두 Transformer.

[Self-Attention (자기 주의)]
----------------------------------------
한 시퀀스 안의 각 위치가 다른 모든 위치를 얼마나 참고할지 가중치를 계산해서, 가중 평균으로 새 표현을 만드는 연산. 질의(Q), 키(K), 값(V) 세 벡터로 계산함.
- Encoder에서는 패치 577개(576 + [CLS])가 서로를 참고해 문맥이 담긴 특징이 됨.

[Multi-Head Attention (멀티헤드 어텐션)]
----------------------------------------
Attention을 여러 개(헤드) 나란히 계산해서 서로 다른 관계를 동시에 보게 하는 방법. 결과를 이어 붙여 합침.
- Encoder와 Decoder의 각 층에 들어 있음. BEiT-Base는 헤드 12개.

[Masked Self-Attention (마스크 자기 주의)]
----------------------------------------
Self-Attention에서 뒤쪽 위치를 가려서, 각 위치가 자기보다 앞의 위치만 보게 하는 방법.
- Decoder에 씀. 학습 때 정답 전체를 한꺼번에 넣어도 아직 쓰지 않은 뒤 토큰을 미리 보지 못하게 함.

[Cross-Attention (교차 주의)]
----------------------------------------
질의는 한 시퀀스(디코더)에서, 키와 값은 다른 시퀀스(인코더 출력)에서 가져오는 Attention.
- Decoder가 다음 토큰을 만들 때 이미지 특징 중 어디를 볼지 정하는 부분. 이미지와 텍스트를 잇는 다리.

[Feed Forward (FFN, 피드포워드 층)]
----------------------------------------
Attention 뒤에 위치마다 따로 적용하는 작은 2층 완전연결 신경망. 각 위치의 표현을 비선형으로 변환함.
- Encoder와 Decoder의 모든 층에 Attention과 짝으로 들어 있음.

[인코더-디코더 (Encoder-Decoder)]
----------------------------------------
입력을 특징으로 바꾸는 인코더와, 그 특징을 보고 출력 시퀀스를 만드는 디코더로 이뤄진 구조. 번역 모델의 기본 형태.
- TrOCR: 이미지 Transformer 인코더 + 텍스트 Transformer 디코더.

[위치 임베딩 (position embedding)]
----------------------------------------
Transformer는 입력 순서를 스스로 알지 못하므로, 위치마다 정해진 벡터를 더해 순서 정보를 넣는 방법.
- TrOCR는 학습되는 1차원 위치 임베딩을 패치와 특수 토큰에 더함.

[토큰 (token)]
----------------------------------------
모델이 한 번에 다루는 단위. 텍스트에서는 단어나 단어 조각, 이미지 Transformer에서는 패치 하나.
- Decoder 출력은 텍스트 토큰, Encoder 입력은 패치 토큰.

[wordpiece (워드피스, 하위 단어)]
----------------------------------------
단어를 자주 나오는 조각으로 나눈 단위. 흔한 단어는 통째로, 드문 단어는 여러 조각으로 표현해서 어휘 크기를 줄이면서도 모든 단어를 쓸 수 있음.
- TrOCR 디코더의 출력 단위. 토크나이저는 Fairseq의 BPE와 SentencePiece. 8번 슬라이드의 "pix" + "els"가 예시(설명용).

[자기회귀 (autoregressive)]
----------------------------------------
앞에서 만든 출력을 다음 단계의 입력으로 다시 넣어 한 개씩 순서대로 생성하는 방식.
- TrOCR Decoder의 생성 방식. [BOS]에서 시작해 [EOS]가 나올 때까지 토큰을 하나씩 만듦.

[[BOS]/[EOS] 토큰 (시작 토큰, 끝 토큰)]
----------------------------------------
문장의 시작과 끝을 표시하는 특수 토큰. [BOS]는 생성을 시작하는 첫 입력, [EOS]는 생성을 멈추라는 신호.
- 학습 때는 [BOS]로 한 칸 민 정답을 입력하고, [EOS]로 끝나는 정답을 목표로 씀.

============================================================
4. TrOCR의 부품
============================================================

[ViT (Vision Transformer, 비전 트랜스포머)]
----------------------------------------
이미지를 고정 크기 패치로 잘라 각 패치를 단어처럼 Transformer에 넣는 이미지 분류 모델. 논문 제목이 "An Image is Worth 16x16 Words".
- TrOCR Encoder가 이 방식으로 이미지를 처리함.

[패치 (patch)]
----------------------------------------
이미지를 바둑판처럼 자른 작은 조각. 각 패치의 픽셀을 한 줄로 펼친 뒤 선형 변환해 벡터로 만듦.
- TrOCR: 384×384 이미지를 16×16 패치로 잘라 24×24 = 576개.

[[CLS] 토큰 (클래스 토큰)]
----------------------------------------
패치 시퀀스 맨 앞에 붙이는 학습 가능한 특수 토큰. 이미지 분류에서는 이 토큰의 출력으로 전체 이미지를 대표함.
- TrOCR는 사전학습 인코더와 맞추기 위해 이 토큰을 그대로 둠.

[BEiT (BERT Pre-Training of Image Transformers)]
----------------------------------------
이미지 패치 일부를 가리고, 가려진 부분을 맞히도록 이미지 Transformer를 사전학습하는 방법. 문장의 가려진 단어를 맞히는 BERT를 이미지에 옮긴 것.
- TrOCR-Base와 Large의 인코더 초기값. Table 1에서 가장 높은 F1.

[DeiT (Data-efficient image Transformer)]
----------------------------------------
ImageNet만으로 효율적으로 학습한 ViT. 큰 CNN 선생 모델에게서 배우는 지식 증류를 씀.
- TrOCR-Small의 인코더 초기값. 증류 토큰도 그대로 둠.

[지식 증류 (knowledge distillation)]
----------------------------------------
큰 선생 모델의 출력을 작은 학생 모델이 따라 하도록 학습시켜, 작으면서도 성능 좋은 모델을 만드는 방법.
- DeiT와 MiniLM이 이 방법으로 만든 모델.

[RoBERTa (Robustly optimized BERT approach)]
----------------------------------------
BERT를 더 많은 데이터와 더 오래, 더 나은 설정으로 학습한 텍스트 Transformer. 문장 이해에 강함.
- TrOCR-Base와 Large의 디코더 초기값(RoBERTa-Large). 언어 지식을 디코더에 가져오는 역할.

[MiniLM]
----------------------------------------
큰 언어모델의 Self-Attention 분포를 따라 하도록 증류해서 만든 작은 텍스트 Transformer.
- TrOCR-Small의 디코더 초기값.

============================================================
5. 학습 방법
============================================================

[사전학습 (pre-training)]
----------------------------------------
목표 과제와 다르거나 더 큰 데이터로 모델을 미리 학습해 일반적인 표현을 익히게 하는 단계.
- TrOCR는 두 겹으로 씀. BEiT·RoBERTa 같은 공개 가중치로 시작하고, 다시 대규모 글자 이미지(1단계 6.84억 줄, 2단계 합성 데이터)로 사전학습함.

[Fine-tuning (파인튜닝, 미세조정)]
----------------------------------------
사전학습한 모델을 목표 과제의 데이터로 조금 더 학습시켜 맞추는 단계.
- SROIE, IAM, 장면 글자 벤치마크 각각에 Fine-tuning해서 평가함.

[전이학습 (transfer learning)]
----------------------------------------
한 과제에서 배운 지식을 다른 과제에 옮겨 쓰는 방법. 사전학습 후 Fine-tuning이 대표적인 형태.
- TrOCR의 핵심 아이디어. 일반 이미지와 일반 텍스트에서 배운 지식을 글자 인식에 옮김.

[데이터 증강 (data augmentation)]
----------------------------------------
학습 이미지에 회전, 흐림 같은 변형을 무작위로 줘서 데이터를 늘리는 방법. 모델이 변형에 덜 민감해지고 과적합이 줄어듦.
- 인쇄체·손글씨: 원본 + 회전(−10~10°), 가우시안 블러, 팽창, 침식, 축소, 밑줄 중 하나를 같은 확률로. 장면 글자: RandAugment.

[teacher forcing (교사 강요)]
----------------------------------------
자기회귀 모델을 학습할 때, 모델이 직접 만든 이전 출력 대신 정답의 이전 토큰을 입력으로 넣는 방법. 모든 위치를 한 번에 병렬로 학습할 수 있음.
- TrOCR 학습: 정답을 [BOS]로 한 칸 밀어서 디코더 입력으로 씀.

[교차 엔트로피 (cross-entropy)]
----------------------------------------
정답 클래스에 모델이 준 확률 p에 대해 −log p로 계산하는 분류 손실. p가 1이면 0, p가 0에 가까울수록 커짐.
- TrOCR의 손실. 위치마다 정답 토큰의 확률로 계산해 평균함.

[빔 서치 (beam search)]
----------------------------------------
생성할 때 매 단계 가장 그럴듯한 후보 여러 개(빔)를 유지하며 나아가, 마지막에 전체 확률이 가장 높은 문장을 고르는 방법. 하나만 고르는 탐욕적 디코딩보다 초반 실수에 강함.
- 논문은 빔 크기 10을 씀.

[탐욕적 디코딩 (greedy decoding)]
----------------------------------------
매 단계 확률이 가장 높은 토큰 하나만 골라 이어 가는 가장 단순한 생성 방법.
- 8번 슬라이드의 설명이 이 방식. 자체 실험 설정은 실험 노트 참고.

============================================================
6. 평가 지표
============================================================

[편집 거리 (edit distance, Levenshtein distance)]
----------------------------------------
한 문자열을 다른 문자열로 바꾸는 데 필요한 최소 바꾸기·지우기·끼워 넣기 횟수. 동적 계획법으로 계산함.
- CER과 WER의 분자. 11번 슬라이드의 정렬이 이 계산 결과.

[CER (Character Error Rate, 문자 오류율)]
----------------------------------------
(바뀐 글자 S + 빠진 글자 D + 끼어든 글자 I) ÷ 정답 글자 수 N. 낮을수록 좋음. 끼어든 글자가 많으면 100%를 넘을 수도 있음.
- IAM 평가 지표(대소문자 구분). 자체 실험의 주 지표.

[WER (Word Error Rate, 단어 오류율)]
----------------------------------------
CER과 같은 계산을 글자 대신 단어 단위로 한 것. 글자 하나만 틀려도 그 단어는 오류.
- 자체 실험에서 CER과 함께 보고.

[정밀도, 재현율, F1 (Precision, Recall, F1 score)]
----------------------------------------
정밀도 = 예측한 것 중 맞은 비율, 재현율 = 정답 중 찾아낸 비율, F1 = 둘의 조화 평균.
- SROIE 평가 지표. 단어 단위로 계산.

[단어 정확도 (word accuracy)]
----------------------------------------
단어 이미지 하나를 통째로 맞힌 비율.
- 장면 글자 벤치마크 평가 지표.
